# Security

Please report a security problem in this package to **support@pipsocket.com**, with "Security" in the subject, rather than in a public issue. Include the version, the runtime and how to reproduce it. We'll reply within two working days.

If your API key may have leaked, roll it at once on the dashboard's **API key** page: see [rolling the key](https://docs.pipsocket.com/authentication#rolling-the-key). A stream opened with the old key stays open until it closes, so engage the kill switch if someone else could trade.

Only the latest release gets security fixes while the package is below 1.0.
